Microsoft Windows 8 Student Companion Program
=============================================

Tue, 26/02/2013 - 09:05

| Thân chào tất cả các bạn sinh viên và thầy cô giáo,<br><br>Với mục đích cùng đồng hành với các bạn sinh viên trong việc học tập và phát triển nền tảng kiến thức lập trình ứng dụng cho hệ điều hành Windows 8. Microsoft xin trân trọng thông báo đến tất cả các bạn sinh viên chương trình **Microsoft Windows 8 Student Companion**.<br><br>Tham gia chương trình:<br><br>Để tham gia chương trình mỗi sinh viên phải upload ứng dụng **Windows 8 Modern UI** của mình lên Windows Store trong khoảng thời gian từ 1/3/2013 – 30/4/2013. Ứng dụng Windows 8 Modern UI này phải thỏa các điều kiện tiêu chuẩn của của một ứng dụng Windows 8. Microsoft sẽ nhận email đăng ký chương trình đến hết ngày 31/5/2013.<br><br>Microsoft cam kết sẽ trao những gói hỗ trợ sau đây cho các bạn sinh viên học sinh khi tham gia vào chương trình:<br><br>1.      Mỗi ứng dụng đạt yêu cầu (\*) tham gia vào chương trình sẽ được tặng voucher tiền mặt trị giá 1.000.000 đồng để phát triển sản phẩm.<br><br>2.      Account Dreamspark Student: với account này các bạn sẽ được download và dùng key miễn phí cho các phần mềm của Microsoft như Visual Studio Professional, Expressions, SQL Server, Windows Embedded, Windows Server ….<br><br>3.      Windows Store developer account (miễn phí): với account này lập trình viên có thể upload và bán ứng dụng của mình trên Microsoft Store dành cho Windows 8. Đối với những lập trình viên hoặc công ty, họ phải trả với giá từ 1 triệu đến 2 triệu đồng cho một tài khoản Windows Store.<br><br>4.      Windows Phone developer account - Marketplace (miễn phí): với account này lập trình viên có thể upload và bán ứng dụng của mình trên Microsoft Marketplace dành cho Windows Phone. Đối với những lập trình viên hoặc công ty, họ phải trả với giá từ 1 triệu đến 2 triệu đồng cho một tài khoản Windows Phone developer account.<br><br>Phạm vi áp dụng chương trình:<br><br>Chỉ áp dụng cho các bạn sinh viên - học sinh đang theo học các trường Đại Học, Cao Đẳng, Trung Học Chuyên Nghiệp, Trung Học Phổ Thông trong cả nước.<br><br>Trân trọng thông báo. |

| **(\*) Quy định chất lượng ứng dụng tham gia chương trình**<br><br>1.      Tích hợp một số chức năng đặc trưng của một ứng dụng Windows 8 Modern UI.<br><br>2.      Thiết kế giao diện đạt chuẩn Windows 8 Modern UI.<br><br>3.      Ứng dụng phải có mục đính sử dụng rõ ràng.<br><br>4.      Không chấp nhận những ứng dụng được sao chép nguyên mẫu từ các ứng dụng đã có sẵn trên store.<br><br>**Tài liệu tham khảo lập trình windows 8 Modern UI**<br><br>Hands on labs: [](http://www.microsoft.com/en-us/download/details.aspx?id=29854)<br>[http://www.microsoft.com/en-](http://www.microsoft.com/en-)<br>us/download/details.aspx?id=29854<br><br>Programming Windows Store apps: [](http://msdn.microsoft.com/en-us/windows/apps/br229516.aspx)<br>[http://msdn.microsoft.com/en-](http://msdn.microsoft.com/en-)<br>us/windows/apps/br229516.aspx<br><br>Windows 8 SDK: [](http://msdn.microsoft.com/en-us/windows/desktop/hh852363.aspx)<br>[http://msdn.microsoft.com/en-](http://msdn.microsoft.com/en-)<br>us/windows/desktop/hh852363.aspx<br><br>The Windows Software Development Kit for Windows 8 (Windows SDK) contains headers, libraries, and a selection of tools that you can use when you create apps that run on Windows operating systems. You can use the Windows SDK, along with your chosen development environment, to write Windows Store apps (only on Windows 8) using web technologies (such as HTML5, CSS3, and JavaScript), native (C++), and managed (C#, Visual Basic) code; desktop applications that use the native (Win32/COM) programming model; or desktop applications that use the managed (.NET Framework) programming model. |
