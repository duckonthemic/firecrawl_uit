SPERANZA – HIRING WINDOWS APPLICATION DEVELOPER
===============================================

Wed, 04/06/2025 - 10:18

**SPERANZA – HIRING WINDOWS APPLICATION DEVELOPER**

**Location:** SH02-22, Sari Town, Sala, No. 74, B2 Street, An Loi Dong Ward, District 2, Ho Chi Minh City
**Position Type**: Full-time
**Department:** Software Development
**Email to Apply:** [thang.hong@speranzainc.com](mailto:thang.hong@speranzainc.com)
, [thao.tran@speranzainc.com](mailto:thao.tran@speranzainc.com)

**ABOUT US:**
Speranza is a technology-driven company specializing in offshore software development, smart IoT solutions, and digital transformation. We collaborate with international clients across Asia and beyond to create innovative software products that power the next generation of connected systems.
We are currently looking for an experienced Windows Application Developer to join our passionate team and contribute to impactful desktop software solutions.

**JOB DESCRIPTION:**
​As a Windows Application Developer, you will be responsible for designing, developing, and maintaining Windows applications using the .NET framework. You will work closely with cross-functional teams including Product Owners, QA, and IoT engineers to deliver stable and high-performing applications.

**RESPONSIBILITIES**​​

* Develop and maintain Windows desktop applications using .NET technologies (C#, WinForms, WPF).
* Work with Product and BA teams to understand functional requirements and translate them into technical solutions.
* Optimize application performance for speed, stability, and scalability.
* Collaborate with the IoT team to integrate hardware devices and sensors into desktop applications.
* Conduct unit testing, participate in peer code reviews, and support QA teams during testing phases.
* Write and maintain technical documentation.
* Continuously improve application architecture, code quality, and deployment processes.

**REQUIREMENTS:**

* ​​At least 1-3 year of hands-on experience in Windows application development using .NET technologies.
* Proficient in C#, .NET Framework, Windows Forms or WPF.
* Experience in optimizing desktop application performance (memory usage, load time, responsiveness).
* Familiarity with source control tools such as Git.
* Solid understanding of object-oriented programming and software development principles.
* Good problem-solving and debugging skills.

**Preferred Qualifications (Nice to Have):**

* Experience in integrating IoT devices or working on IoT-related applications.
* Familiarity with serial port communication, USB devices, or sensor APIs.
* Knowledge of multi-threading and asynchronous programming.
* English reading and basic communication skills.

**WHY JOIN SPERANZA?**

* ​Work on innovative projects in IoT and smart system development.
* Dynamic working environment with international clients.
* Competitive salary and growth opportunities.
